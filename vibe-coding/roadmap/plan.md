# Vibe Coding 学习路线

## 阶段 1：基础认知（已完成）
- [x] 01-overview：基本概念、工具链准备、核心概念
- [x] 01-demo：最小可体验 Demo（温度转换器对比）

## 阶段 2：实战项目（待开始）
- 用 Vibe Coding 完成一个完整小项目（如 Todo App、个人博客页面）
- 练习"迭代精化"：先出骨架 → 加功能 → 修 bug → 加样式
- 记录每次 prompt 和 AI 产出，分析哪些 prompt 效果好/差

## 阶段 3：提示词进阶（待开始）
- 学习结构化 prompt 写法（角色设定 + 任务描述 + 约束 + 示例）
- 对比不同 AI 工具（Claude Code / Cursor / Copilot）对同一段 prompt 的产出差异
- 建立自己的 prompt 模板库（CRUD、API、组件、测试等场景）

## 阶段 4：中型项目管理（待开始）
- 学习如何在多文件项目中保持 AI 的上下文连贯
- 实践"分模块开发"：每次只让 AI 处理一个模块
- 引入测试：让 AI 同时生成代码和对应的单元测试

## 阶段 5：前沿探索（待开始）
- 了解 Karpathy 提出的 "Agentic Engineering" 概念
- 探索 AI Agent 自主完成"写代码 → 测试 → 修复"的闭环
- 关注 vibe coding 在 CI/CD、代码审查、文档生成等场景的应用
