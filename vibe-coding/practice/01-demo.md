# Vibe Coding 最小体验

## 目标
用同一段 prompt，分别用"传统编程思维"和"Vibe Coding 思维"完成同一个任务，感受差异。

---

## 体验任务：写一个温度转换器

### 第一轮：传统方式（你自己写代码）

1. 打开编辑器，手动写一个华氏度 → 摄氏度的转换函数
2. 写 3 个测试用例（0°F、32°F、212°F）
3. 运行并验证

预计耗时：5~15 分钟（取决于你对语言的熟悉程度）

---

### 第二轮：Vibe Coding 方式（让 AI 写代码）

**Step 1：发送第一段 prompt**
```
用 Python 写一个温度转换器，支持华氏度和摄氏度互相转换。
要求：有清晰的函数命名，包含 3 个测试用例。
```

**观察**：AI 是否一次性给出了完整代码？花了几秒？

**Step 2：迭代精化**
```
给这个转换器加一个命令行交互界面，
让用户输入 "35F" 就转成摄氏，输入 "20C" 就转成华氏。
```

**观察**：AI 是否正确理解了你的意图？代码能不能直接运行？

**Step 3：再次迭代**
```
加一个功能：如果输入格式不对（比如 "abc"），给出友好的错误提示，而不是崩溃。
```

**观察**：AI 是否正确处理了边界情况？

---

### 对比总结

| 维度 | 传统方式 | Vibe Coding |
|------|---------|-------------|
| 首次可运行 | 5~15 分钟 | 10~30 秒 |
| 添加交互界面 | 再花 10 分钟 | 再花 10 秒（prompt） |
| 错误处理 | 手动写 try/except | 一句话描述需求 |
| 你做的事 | 查语法、写代码、debug | 描述意图、验证结果 |
| 你需要的知识 | 语言语法 + 标准库 | 能说清楚"我想要什么" |
